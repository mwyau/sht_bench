# Legacy matrix figures

56 regenerated GL/CC figures for the 180 conda-forge pyspharm 1.0.9 timing records on Python 3.14.9 and NumPy 2.5.4. Each record retains seven raw samples, three warmups, and the 0.2-second minimum timing window. Pyspharm is serial; requested thread count is retained as a workload dimension but does not change the native thread count.

- [By lmax and thread count](by-lmax/)
- [By requested thread count and lmax](by-threads/)

The plotted data are [legacy-matrix.json](../../../data/pyspharm-conda-forge-2026-10-25/legacy-matrix.json) and [legacy-matrix.csv](../../../data/pyspharm-conda-forge-2026-10-25/legacy-matrix.csv). No other backend measurements are overlaid.
