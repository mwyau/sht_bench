# pyspharm conda-forge figures — Python 3.14.9

All figures here are regenerated from the tracked q1 and legacy result exports. The backend color remains red; conda-forge build style is dash-dot in the legacy plots. The q1 plots show one backend only, so they contain no performance ratios.

- [Source q1 figures](source-q1/README.md): 70 timing, setup, native setup, memory, and error-versus-latency plots from 126 validated timings across three process rounds.
- [Legacy matrix figures](legacy/README.md): 56 GL/CC plots from 180 Python 3.14.9 records at requested thread counts 1, 2, 4, 8, and 16.
- [q1 setup versus warm timing](q1-setup-vs-warm.png) and [first-call versus warm timing](q1-first-call-vs-warm.png) summarize the same q1 run.
