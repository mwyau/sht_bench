# pyspharm conda-forge figures — Python 3.14.9

All figures here are regenerated from tracked conda-forge pyspharm results and matched Python 3.14 controls. The backend color remains red; conda-forge build style is dash-dot in the legacy plots. The standalone q1 plots show one backend only; the matched reports add precision-compatible comparisons.

- [Source q1 figures](source-q1/README.md): 70 timing, setup, native setup, memory, and error-versus-latency plots from 126 validated timings across three process rounds.
- [Legacy matrix figures](legacy/README.md): 56 GL/CC plots from 180 Python 3.14.9 records at requested thread counts 1, 2, 4, 8, and 16.
- [Matched L64 control](matched-q1-l64/README.md): 100 timing, setup, memory, and accuracy figures for workload groups containing pyspharm, with 147 exact matched cell pairs.
- [Matched L360 CC control](matched-cc-l360/README.md): 10 figures and six exact pyspharm/DUCC cell pairs.
- [q1 setup versus warm timing](q1-setup-vs-warm.png) and [first-call versus warm timing](q1-first-call-vs-warm.png) summarize the same q1 run.

The q1 gallery previews are split across [figures 1–48](source-q1/figures-0001.md) and [figures 49–70](source-q1/figures-0002.md).
